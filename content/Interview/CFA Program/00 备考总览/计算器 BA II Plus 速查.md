# BA II Plus 速查（考前必须肌肉记忆）

← 返回 [[CFA Program]]

> **90 秒一道题**。计算器操作慢 10 秒 × 60 道计算题 = 白丢 10 分钟。这份笔记的目标是让按键变成条件反射，考场上不需要想。

---

## 🔧 开考前必做的三项设置

买来第一天就设好，之后每次练习都用同一个设置。

| 设置 | 按键 | 为什么 |
|---|---|---|
| 小数位显示 9 位 | `2ND` `FORMAT` → 输入 `9` → `ENTER` | 默认只显示 2 位。中间步骤四舍五入会导致最终答案对不上任何一个选项 |
| 每年复利 1 次 | `2ND` `P/Y` → 输入 `1` → `ENTER` → `↓` → 输入 `1` → `ENTER` | **最高频的计算器坑**。P/Y 默认是 12，会让所有 TVM 计算全错 |
| 改为链式运算（可选） | `2ND` `FORMAT` → `↓`×几次到 `Chn/AOS` → `2ND` `SET` | `Chn` 按顺序算，`AOS` 按运算优先级算。建议用 `Chn`，符合直觉 |

**清除键三兄弟（分清楚，别混）**：

| 按键 | 作用 |
|---|---|
| `CE/C` | 清当前输入的数字 |
| `2ND` `CLR TVM` | 清 TVM 五个寄存器（N/I/Y/PV/PMT/FV） |
| `2ND` `CLR WORK` | 清当前功能区（CF、DATA、BOND 等）的数据 |
| `2ND` `RESET` `ENTER` | 恢复出厂设置 ⚠️ **会把 DEC 和 P/Y 设置一起清掉，用完必须重设** |

> 🚨 **每道题开始前先按 `2ND` `CLR TVM`**。上一题残留的 PMT 值是最经典的失分方式。

## 💰 TVM（时间价值）—— 最高频

五个键：`N` `I/Y` `PV` `PMT` `FV`

**规则**：已知四个 → 按第五个键 → `CPT` 前置。
**符号约定**：现金流出为负、流入为正。PV 和 FV **必须一正一负**，否则报 `Error 5`。

| 题型 | 操作 |
|---|---|
| 求终值 | 输 `N` `I/Y` `PV`(负) `PMT` → `CPT` `FV` |
| 求年金现值 | 输 `N` `I/Y` `PMT` `FV` → `CPT` `PV` |
| 求隐含利率 | 输 `N` `PV`(负) `PMT` `FV` → `CPT` `I/Y` |
| 求期数 | 输 `I/Y` `PV`(负) `PMT` `FV` → `CPT` `N` |

**期初年金（annuity due）**：`2ND` `BGN` → `2ND` `SET` → `2ND` `QUIT`。屏幕上方出现 `BGN` 字样。
> ⚠️ **算完立刻切回 END**，忘记切回会污染后面所有题。

**半年付息债券**：`I/Y` 输**年利率**、`N` 输**期数**时，如果 P/Y 设成 1（推荐），就要自己手动折半：`N` = 年数×2，`I/Y` = 年利率÷2，`PMT` = 年息÷2。

## 📊 CF 工作表（NPV / IRR）—— Corporate Issuers 必考

```
CF → 2ND CLR WORK          （先清空！）
CF0 = 初始投资（负数）→ ENTER ↓
C01 = 第1期现金流 → ENTER ↓
F01 = 该现金流连续出现几次 → ENTER ↓
C02 = ... （重复）
NPV → I = 折现率 → ENTER ↓ → CPT      得到 NPV
IRR → CPT                              得到 IRR
```

> `F0x` 是**频率**，用来压缩连续相同的现金流。5 年每年 100 → `C01=100, F01=5`，不用输 5 次。

---

## 📈 DATA + STAT 工作表（均值 / 标准差 / 回归）

```
2ND DATA → 2ND CLR WORK
X01 = 值 → ENTER ↓ ↓      （单变量时跳过 Y）
2ND STAT → 2ND SET 切换模型（1-V 单变量 / LIN 线性回归）
↓ 逐个翻：n, x̄, Sx(样本标准差), σx(总体标准差), ...
```

> ⚠️ **`Sx` 是样本标准差（除 n−1），`σx` 是总体标准差（除 n）**。CFA 题目里绝大多数问的是**样本**标准差 → 用 `Sx`。这是 Quant 送命题第一名。

## 🔢 其他高频按键

| 功能 | 按键 |
|---|---|
| 自然对数 ln | `LN` |
| e 的 x 次方 | `2ND` `e^x` |
| 幂运算 x^y | `y^x` |
| 阶乘 n! | `2ND` `x!` |
| 组合数 nCr | 输 n → `2ND` `nCr` → 输 r → `=` |
| 排列数 nPr | 输 n → `2ND` `nPr` → 输 r → `=` |
| 正负号切换 | `+/−`（**不是减号**） |
| 存到内存 | `STO` + `0~9` |
| 取出内存 | `RCL` + `0~9` |
