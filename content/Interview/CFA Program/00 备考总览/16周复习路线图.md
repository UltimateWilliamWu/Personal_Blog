# 16 周复习路线图（2026-07-27 → 考前）

← 返回 [[CFA Program]]

## 设计原则

1. **每周 12 小时 = 主线 11h + Ethics 1h**。Ethics 拆成每周 1 小时贯穿全程，不做最后突击 —— 伦理靠的是反复曝光形成条件反射，不是短期记忆。
2. **FSA 给 3 周**（W4–W6），因为你会计零基础，而它是 Corporate Issuers 和 Equity 估值的地基。
3. **Quant 压到 1 周**，你有量化背景，这是复习不是学习。省下的时间转给 FSA。
4. **一轮做题不后置**：每个 module 学完立刻做 LES practice questions，错题当场进 [[错题本]]。
5. **最后 3 周（W14–W16）不学新东西**，只做错题回炉 + 全真模考。

## 📉 落后了怎么办（分级预案）

进度落后是常态，关键是**按权重砍，不按顺序砍**。

**落后 1 周** → 压缩 Alt Inv 和 Derivatives 的深度。这两科在 L1 是概念题为主，理解框架 + 刷题就够，不用抠细节。

**落后 2–3 周** → 触发以下取舍：
- ✂️ 砍：Derivatives 的 binomial model 手算细节、Alt Inv 的各类另类资产尽调细节、Quant 的 big data techniques
- 🛡 绝不砍：Ethics（15–20%）、FSA 三张表和比率、FI 的 duration/convexity、Equity 的 DDM/multiples
- 判断标准：**权重 ÷ 学习难度**。Ethics 权重最高且难度最低 → 性价比第一，永远优先。

**落后 4 周以上** → 认真考虑改到 2027 年 2 月考期。Level I 通过率长期在 40% 上下，硬考一次不过要花 1000+ 美金和 4 个月，代价比延期高。
