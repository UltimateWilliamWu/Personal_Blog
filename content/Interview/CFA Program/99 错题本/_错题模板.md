# 错题模板

← 返回 [[错题本]]

复制下面这块，填进 [[错题本]] 的「错题记录」区。

---

```markdown
### ❌ [编号] [一句话题眼，不是题干原文]

| | |
|---|---|
| **科目** | Fixed Income |
| **来源** | LES Module 6.4 EOC Q12 / Mock 1 Q87 |
| **日期** | 2026-__-__ |
| **错因** | **B 概念混淆** |
| **我选** | B | **正确** | C |

**题干要点**（用自己的话压缩到两行，不要抄原文）
> ……

**我当时的思路 / 错在哪**

**正确逻辑**（自己复述一遍，不许抄答案解析）

> ……（往往和题面看起来考的不是一回事）

**陷阱词 / 干扰项设计**

**回炉**：一刷 ❌ 2026-__-__ ｜ 二刷 __ ｜ 三刷 __
```

---

## ✍️ 填写要求（严格执行，否则这本笔记会退化成答案抄写本）

1. **「一句话题眼」不是题干原文**。写「Macaulay vs. Modified duration 在利率变动方向上的符号」，不写「一个 10 年期债券……」。半年后你只会靠题眼检索。

2. **「正确逻辑」必须自己写**。抄解析等于没做。如果写不出来 → 说明你还没懂 → 直接把题发给 Claude 重讲。

3. **「这题真正在考什么」是最有价值的一栏**。CFA 很多题的外壳和内核不一样：一道看起来在算 NPV 的题，考点可能是 sunk cost 不计入现金流。填这栏才能实现举一反三。

4. **错因只填一个主因**。如果既有概念不清又有粗心，填**更根本**的那个。

5. **不确定就标注**。蒙对的题也要记 —— 在题眼后加 `[蒙对]`。蒙对的题下次不一定蒙对，它和错题的风险等级是一样的。

---

## 🚀 最快的用法

不用自己填。直接把题目发给我，说：

> 「这题我错了，选了 B，答案是 C，题干是……」

我会：
1. 判断你到底卡在哪一步（不是简单讲答案）
2. 归类错因
3. 补上「这题真正在考什么」和干扰项设计逻辑
4. 按模板写进 [[错题本]]
5. 如果是概念混淆（错因 B），顺手在对应科目笔记里补一张对比表
