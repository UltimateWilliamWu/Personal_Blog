# 160. Intersection of Two Linked Lists

← [[Work/LeetCode/index|LeetCode 题解]]

> 链表双指针的经典题。核心洞察：两条相交链表的**尾部一定是对齐的**。

Given the heads of two singly linked-lists `headA` and `headB`, return _the node at which the two lists intersect_. If the two linked lists have no intersection at all, return `null`.

For example, the following two linked lists begin to intersect at node `c1`:

![](https://assets.leetcode.com/uploads/2021/03/05/160_statement.png)

The test cases are generated such that there are no cycles anywhere in the entire linked structure.

**Note** that the linked lists must **retain their original structure** after the function returns.

**Custom Judge:**

The inputs to the **judge** are given as follows (your program is **not** given these inputs):

- `intersectVal` - The value of the node where the intersection occurs. This is `0` if there is no intersected node.
- `listA` - The first linked list.
- `listB` - The second linked list.
- `skipA` - The number of nodes to skip ahead in `listA` (starting from the head) to get to the intersected node.
- `skipB` - The number of nodes to skip ahead in `listB` (starting from the head) to get to the intersected node.

The judge will then create the linked structure based on these inputs and pass the two heads, `headA` and `headB` to your program. If you correctly return the intersected node, then your solution will be **accepted**.

## ⚠️ 第一个坑：比的是「节点」不是「值」

「相交」= **同一个节点对象**（内存地址相同），不是 `val` 相等。所以 Python 里要用 `is`，不要用 `==`。

> 在 C / C++ 里 `p == q` 本来就是比指针地址，天生就是对的语义。Python 的 `is` 其实是在补 C 免费送的东西。

而且**一旦相交，后面就全部重合** —— 单链表每个节点只有一个 `next`，不可能再岔回去：

```
A:  a1 → a2 ↘
              c1 → c2 → c3 → None
B:  b1 → b2 → b3 ↗
```

**所以尾部一定是对齐的。** 这个观察是下面两个 $O(1)$ 空间解法的地基。

---

## Solution 1 · 对齐尾部 + 齐头并进（推荐主力解）

**大白话：** 既然尾部对齐，那就先量出两条链的长度差，让**长的那条先走几步**，把两个指针挪到「距离终点一样远」的位置，之后同步前进，一定同时到达交点。

> 🚶 **类比**：两个人从不同起点走向同一条汇合的路。谁的路更长，谁就先出发几步，之后同步前进，必定在岔口相遇。

```Python
class Solution:
    def getIntersectionNode(self, headA, headB):
        def length(head):
            n = 0
            while head:
                n += 1
                head = head.next
            return n

        lenA, lenB = length(headA), length(headB)

        # 统一让 A 当"长的那条"，省掉一半分支
        if lenA < lenB:
            headA, headB = headB, headA
            lenA, lenB = lenB, lenA

        # 长的先走差值步，此时两指针到末尾距离相等
        for _ in range(lenA - lenB):
            headA = headA.next

        # 齐头并进
        while headA:
            if headA is headB:
                return headA
            headA = headA.next
            headB = headB.next
        return None
```

时间 $O(n + m)$，空间 $O(1)$。

## Solution 2 · 双指针换轨（代码最短，面试加分）

**大白话：** pA 走完 A 就跳到 B 的头，pB 走完 B 就跳到 A 的头。两人走的**总路程完全相同**，所以必定在交点相遇。

```Python
class Solution:
    def getIntersectionNode(self, headA, headB):
        pA, pB = headA, headB
        while pA is not pB:
            pA = pA.next if pA else headB
            pB = pB.next if pB else headA
        return pA          # 相交返回交点，不相交时两者同时为 None
```

### 为什么一定相遇？

设 A 独有段长 $a$，B 独有段长 $b$，公共段长 $c$。注意指针换轨前会**先变成一次 `None`**（占一步），两边对称所以能抵消：

$$
\underbrace{(a + c)}_{\text{走完 A}} + \underbrace{1}_{\text{None}} + b \;=\; \underbrace{(b + c)}_{\text{走完 B}} + \underbrace{1}_{\text{None}} + a
$$

两边相等 → 同时到达交点。

**不相交时会不会死循环？** 不会。此时 $c = 0$，pA 走 $a + b + 1$ 步变 `None`，pB 也是，两个 `None` 相等，循环退出返回 `None`。

### `pA = pA.next if pA else headB` 怎么读

这是 Python 的**三元表达式**（`值A if 条件 else 值B`），等价于：

```Python
if pA:                 # pA 不是 None
    pA = pA.next
else:                  # pA 已经走过尾巴变成 None 了
    pA = headB
```

> ⚠️ 判断的是 **`pA` 本身**，不是 `pA.next`。如果改成 `if pA.next`（跳过 `None` 那一步），两条不相交的链表就会**永远错开一步、永远不相等** → 死循环。

### 官方样例逐步追踪

```
A: 4 → 1 → 8 → 4 → 5          (a=2, c=3)
B: 5 → 6 → 1 → 8 → 4 → 5      (b=3, c=3)
                ↑ 交点是这个 8
```

| step | pA | pB | 相等? |
|---|---|---|---|
| 0 | A的4 | B的5 | ✗ |
| 1 | A的1 | 6 | ✗ |
| 2 | **8**(共享) | B的1 | ✗ |
| 3 | 4(共享) | **8**(共享) | ✗ |
| 4 | 5(共享) | 4(共享) | ✗ |
| 5 | `None` | 5(共享) | ✗ |
| 6 | → headB=5 | `None` | ✗ |
| 7 | 6 | → headA=4 | ✗ |
| 8 | **B的1** | **A的1** | ✗ ← 关键！ |
| 9 | 8(共享) | 8(共享) | ✅ 返回 |

**第 8 步是这题最好的教学点**：两边 `val` 都是 `1`，但一个是 A 自己的节点、一个是 B 自己的节点，是两个不同对象。用 `is` 比较 → 不相等，正确继续。如果写成 `pA.val == pB.val`，**在这里就会错误返回**。

## Solution 3 · 哈希集合（最直观，先会这个）

**大白话：** 把 A 的所有节点丢进一个集合，再遍历 B，第一个能在集合里查到的就是交点。

```Python
class Solution:
    def getIntersectionNode(self, headA, headB):
        visited = set()
        cur = headA
        while cur:
            visited.add(cur)     # 存节点本身，不是 cur.val
            cur = cur.next
        cur = headB
        while cur:
            if cur in visited:   # set 按对象身份哈希，正好是我们要的语义
                return cur
            cur = cur.next
        return None
```

思路最好想，但要多花 $O(n)$ 空间。跟 [[1. Two Sum]] 是同一个「先建索引再查询」套路。

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 暴力双循环 | $O(n \times m)$ | $O(1)$ | 会 TLE |
| **Solution 1** 对齐尾部 | $O(n + m)$ | $O(1)$ | **主力解，逻辑最清楚** |
| **Solution 2** 双指针换轨 | $O(n + m)$ | $O(1)$ | 代码最短，需要会证明 |
| **Solution 3** 哈希集合 | $O(n + m)$ | $O(n)$ | 最好想 |

## ⚠️ 易错点清单

1. **用 `is` 而非 `==`** —— 比节点身份，不是比值
2. **不能改 `next` 指针** —— 题目明确要求返回后链表保持原结构。所以「把 A 的尾接到 B 的头转成环形检测」这类解法要么别用，要么做完必须断开
3. **换轨法的跳转条件是 `if pA`，不是 `if pA.next`**
4. **空链表**天然被处理（`headA` 为 `None` 时循环直接不进）
5. `Optional` 需要 `from typing import Optional`，LeetCode 平台已内置，本地跑要自己加
