# 349. Intersection of Two Arrays

← [[Work/LeetCode/index|LeetCode 题解]]

> 集合（set）的模板题。结果要**去重**，这正是 set 的天职。

Given two integer arrays `nums1` and `nums2`, return _an array of their intersection_. Each element in the result must be **unique** and you may return the result in **any order**.

**Example 1:**

```
Input:  nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2]
```

**Example 2:**

```
Input:  nums1 = [4,9,5], nums2 = [9,4,9,8,4]
Output: [9,4]      # [4,9] 也算对
```

**Constraints:**

- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 1000`

---

## 💡 思路（大白话）

把第一个数组整个倒进一个**集合**里（自动去重），再拿第二个数组的每个数去问一句「你在不在里面」。在的就收进结果 —— 结果也用 set 装，顺便把重复的也去掉了。

> 📋 **类比**：手里两份名单，想找出都出现的人。你不会拿甲名单的每个人去乙名单从头翻一遍，而是先把乙名单做成一本**花名册**，然后甲名单逐个查册。

**跟 [[1. Two Sum]] 是同一个套路 —— 先建索引，再查询。** 区别只在于：Two Sum 要记「这个值在第几位」（用 `dict`），这里只需要记「这个值存不存在」（用 `set`）。

---

## 解法一：哈希集合（推荐，思路最清楚）

```Python
class Solution(object):
    def intersection(self, nums1, nums2):
        """
        :type nums1: List[int]
        :type nums2: List[int]
        :rtype: List[int]
        """
        seen = set(nums1)        # ① 第一个数组建成花名册（自动去重）
        result = set()           # ② 结果也用 set，天然满足"unique"
        for num in nums2:
            if num in seen:      # ③ 逐个查册
                result.add(num)
        return list(result)
```

## 解法二：集合运算（Python 一行版）

```Python
class Solution(object):
    def intersection(self, nums1, nums2):
        return list(set(nums1) & set(nums2))
```

`&` 就是集合的交集运算。刷题时可以这么写，但**面试时最好写解法一** —— 一行版把逻辑藏进了标准库，面试官看不到你会不会。

## 解法三：数组计数（利用值域限制）

Constraints 里写了取值范围是 `0 ~ 1000`，**值域有限**，所以可以像 [[242. Valid Anagram]] 那样直接开数组当哈希表用：

```Python
class Solution(object):
    def intersection(self, nums1, nums2):
        seen = [0] * 1001
        for num in nums1:
            seen[num] = 1
        return [num for num in set(nums2) if seen[num]]
```

比 `set` 更快（数组访问没有哈希计算开销），但**依赖题目给的值域**，题目一改就失效。

---

## 复杂度

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 哈希集合 | $O(n + m)$ | $O(n)$ | 通用，推荐 |
| 集合运算 | $O(n + m)$ | $O(n)$ | 同上，只是写法短 |
| 数组计数 | $O(n + m)$ | $O(1)$ | 常数最小，但绑死值域 |

---

## ⚠️ 易错点

1. **结果必须去重**。用 `set` 装结果就自动解决了；如果用 `list` 装，`nums2 = [2,2]` 会输出 `[2,2]`。
2. **别忘了 `list()` 转回来**。题目要求返回数组，直接返回 `set` 会 WA。
3. **数组计数法要看清 Constraints**。值域是 `0~1000` 所以开 1001 格（下标 0 到 1000 都要能放）。如果值可能为负或范围很大，这招就不能用。
