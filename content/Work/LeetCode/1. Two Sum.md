# 1. Two Sum

← [[Work/LeetCode/index|LeetCode 题解]]

> 哈希表入门第一题。核心是把「找配对」转化成「记录 + 查询」。

Given an array of integers `nums` and an integer `target`, return _indices of the two numbers such that they add up to `target`_.
You may assume that each input would have **_exactly_ one solution**, and you may not use the _same_ element twice.
You can return the answer in any order.

---

## 💡 思路（大白话）

边走边把见过的数记在**小本子**上。每遇到一个新数，先问一句：「我还差的那个数（`target - 当前数`），本子上有吗？」

- **有** → 配对成功，返回两个下标
- **没有** → 把当前这个数记进本子，继续往后走

> 🛒 **类比**：超市凑满减，手上拿了 30 块的东西，还差 70。你不会把整个货架重新翻一遍 —— 你只看购物车里有没有 70 的。

**核心转变**：从「拿每个数去跟所有数比一遍」变成「每个数只经手一次，查表判断」。

---

## 解法一：Brute Force（暴力双循环）

两层循环穷举所有配对。能过，但不是考点。

```C
int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
    int* result=(int*)malloc(2*sizeof(int));
    for(int i=0;i<numsSize;i++){
        for(int j=i+1;j<numsSize;j++){
            if((nums[i]+nums[j])==target){
                result[0]=i;
                result[1]=j;
                *returnSize=2;
                return result;
            }
        }
    }
    free(result);
    *returnSize = 0;
    return NULL;
}
```

```Python
class Solution(object):
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):  # 注意 j 从 i+1 开始
                if nums[i] + nums[j] == target:
                    return [i, j]
```

> 📌 上面那份 C 代码值得留意：光是「怎么把答案还回去」就占了 `malloc` / `*returnSize` / `free` 三行样板。这也是纯 C 刷题时容易**被逼着降级解法**的原因 —— 为一道 Two Sum 手撸哈希表不划算，于是就写了 $O(n^2)$。

## 解法二：哈希表（推荐）

```Python
class Solution(object):
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        seen = {}                       # 小本子：值 -> 下标
        for i, num in enumerate(nums):
            need = target - num         # 我还差这个数
            if need in seen:            # ① 先查表
                return [seen[need], i]
            seen[num] = i               # ② 再登记自己
        return []
```

| 解法 | 时间 | 空间 |
|---|---|---|
| 暴力双循环 | $O(n^2)$ | $O(1)$ |
| 哈希表 | $O(n)$ | $O(n)$ |

---

## ⚠️ 易错点

1. **必须「边走边记」，不能一开始把整个数组塞进字典**
   否则 `nums = [3, 2, 4], target = 6` 时，第 0 个数 3 会跟**自己**配对，返回 `[0, 0]` —— 违反「不能重复使用同一个元素」。
2. **查表要在登记之前**（代码里 ① 必须在 ② 前面）
   顺序反了就是上面那个自己配自己的 bug。
3. **记的是「值 → 下标」**，不是「下标 → 值」，因为题目要返回的是下标。
