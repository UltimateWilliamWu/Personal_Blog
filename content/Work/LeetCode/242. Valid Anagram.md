# 242. Valid Anagram

← [[Work/LeetCode/index|LeetCode 题解]]

> 计数法的模板题。字符集有限时，哈希表可以退化成一个定长数组，更快更省。

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

---

## 💡 思路（大白话）

给 26 个字母各摆一个格子：

- 遍历第一个词 `s`，每出现一个字母，对应格子 **+1**
- 遍历第二个词 `t`，每出现一个字母，对应格子 **−1**
- 最后所有格子都归零 → 两边字母完全一样

> 🧱 **类比**：两袋积木一不一样？不用一块块配对，只要数「红的几块、蓝的几块」，两边数字全对上就行。

**为什么不用排序？** `sorted(s) == sorted(t)` 也对，但那是 $O(n \log n)$；计数法只扫两遍，是 $O(n)$。

---

## 解法：Frequency Counting（计数法）

```C
//计数法非常适用该题目 适用场景：字母，有限字符集
bool isAnagram(char* s, char* t) {
    // 如果长度不同，不可能是字母异位词
    if (strlen(s) != strlen(t)) {
        return false;
    }
    int count[26] = {0}; // 用于统计字符频率
    // 遍历字符串 s，统计每个字符的频率
    for (int i = 0; s[i] != '\0'; i++) {
        count[s[i] - 'a']++;
    }
    // 遍历字符串 t，减少对应字符的频率
    for (int i = 0; t[i] != '\0'; i++) {
        count[t[i] - 'a']--;
        if (count[t[i] - 'a'] < 0) { // 如果某个字符出现次数不足
            return false;
        }
    }
    return true;
}
```

```Python
class Solution(object):
    def isAnagram(self, s, t):
        """
        :type s: str
        :type t: str
        :rtype: bool
        """
        if len(s) != len(t):
            return False
        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord('a')] += 1
        for ch in t:
            idx = ord(ch) - ord('a')
            count[idx] -= 1
            if count[idx] < 0:          # 提前退出：t 里这个字母比 s 多
                return False
        return True
```

时间 $O(n)$，空间 $O(1)$（26 个格子是常数，跟输入规模无关）。

---

## 🔍 两个值得学的细节

**① `s[i] - 'a'` 是在做「字母 → 下标」的映射**

字符在内存里就是数字（`'a'` = 97, `'b'` = 98…）。所以 `'c' - 'a' = 2`，正好是 c 在 26 个格子里的位置。这是有限字符集问题的通用技巧。

**② 提前退出的优化**

一旦某个格子被减成负数，立刻返回 `false` —— 说明 `t` 里这个字母比 `s` 多，后面不用再看了。

> 严格说，因为开头已经判过长度相等，「某个字母多」必然意味着「另一个字母少」，所以这一步只是**提前结束**，不影响正确性。但如果去掉长度判断，这个检查就变成**必需**的了。

---

## ⚠️ 易错点

1. **先判长度**。长度不同直接 `false`，能省掉后面一堆判断。
2. **只适用于有限字符集**。题目限定小写字母才能用 26 格数组；如果输入含 Unicode（进阶版就是这么问的），必须换成哈希表 `dict` / `unordered_map`。
3. Python 里 `Counter(s) == Counter(t)` 一行就能过，但**面试时要能手写计数版** —— 考的是这个思路，不是标准库。
