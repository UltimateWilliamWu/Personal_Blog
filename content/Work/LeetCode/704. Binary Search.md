# 704. Binary Search

← [[Work/LeetCode/index|LeetCode 题解]]

> 二分的模板题。真正的考点不是「砍一半」，而是**区间定义与循环条件必须配套**。

Given an array of integers `nums` which is sorted in ascending order, and an integer `target`, write a function to search `target` in `nums`. If `target` exists, then return its index. Otherwise, return `-1`.
You must write an algorithm with `O(log n)` runtime complexity.

> [!note] 二分查找
> 使用场景：
> 1. **数组中无重复元素**（可选）取决于题目要求返回是否唯一
> 2. **有序数组** / 有序区间（硬性条件）

---

## 💡 思路（大白话）

只看正中间那个数：

- 正好等于目标 → 找到了
- 比目标**大** → 目标只可能在**左半边**，右边整片直接扔掉
- 比目标**小** → 目标只可能在**右半边**，左边整片直接扔掉

每比一次，搜索范围砍掉一半。

> 📖 **类比**：查字典。你不会从 A 一页页翻到 Z，而是随手翻到中间，看看该往前还是往后。

**为什么快得离谱？** 一千万个数，最多 24 次就能定位 —— 因为 $2^{24} > 10^7$。这就是 $O(\log n)$ 的威力。

**前提是必须有序** —— 无序数组里，「中间比目标大」推不出「目标在左边」，整个逻辑就塌了。

---

## ⭐ 核心：两种区间写法（这题唯一的难点）

绝大多数人写二分写错，都是因为**区间定义和循环条件没对齐**。先想清楚 `right` 这个位置**算不算在搜索范围内**，剩下三件事就全被决定了：

| | **左闭右闭** `[left, right]` | **左闭右开** `[left, right)` |
|---|---|---|
| `right` 初值 | `len(nums) - 1` | `len(nums)` |
| `right` 本身在范围内吗 | ✅ 在 | ❌ 不在（取不到） |
| 循环条件 | `while left <= right` | `while left < right` |
| 排除右半边时 | `right = mid - 1` | `right = mid` |

**怎么记：**

- **右闭**：`right` 是能取到的合法位置 → `left == right` 时区间里还剩一个数，**得进循环检查** → 用 `<=`；既然 `mid` 已经查过了，就要跳过它 → `right = mid - 1`
- **右开**：`right` 取不到 → `left == right` 时区间已经空了，**不能进循环** → 用 `<`；`mid` 本身就是取不到的边界，赋成 `right = mid` 天然排除了它

**混着写的后果**：`while left < right` 配 `right = mid - 1` 会漏掉边界元素；`while left <= right` 配 `right = mid` 会死循环。

---

## 写法一：左闭右闭 `[left, right]`

```Python
class Solution(object):
    def search(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        left = 0
        right = len(nums) - 1        # right 是合法下标，能取到
        while left <= right:         # 配 <=
            mid = (right - left) // 2 + left
            num = nums[mid]
            if num == target:
                return mid
            if num < target:
                left = mid + 1
            else:
                right = mid - 1      # 配 mid - 1
        return -1
```

## 写法二：左闭右开 `[left, right)`

```Python
class Solution(object):
    def search(self, nums, target):
        left = 0
        right = len(nums)            # right 取不到，所以是长度不是长度-1
        while left < right:          # 配 <
            mid = (right - left) // 2 + left
            num = nums[mid]
            if num == target:
                return mid
            if num < target:
                left = mid + 1
            else:
                right = mid          # 配 mid
        return -1
```

## 对照：暴力解法

```Python
# O(n)，没有利用"有序"这个条件 —— 本题会因为要求 O(log n) 而不合格
for i in range(len(nums)):
    if nums[i] == target:
        return i
return -1
```

---

## ⚠️ 易错点

1. **区间三件套必须配套**（见上表）—— 这是二分唯一真正的坑。
2. **`mid` 的写法**：`(right - left) // 2 + left` 而不是 `(left + right) // 2`。
   Python 整数无上限，两种都对；但**在 C / C++ / Java 里 `left + right` 会溢出**（数组极大时）。养成写前者的习惯，以后换语言不用改。
3. **必须先确认数组有序**。题目没说有序就想用二分，先问自己「能排序吗？排序的 $O(n \log n)$ 会不会已经超过直接遍历的 $O(n)$？」
4. **返回 `-1` 别忘了**。循环正常结束意味着没找到。
