# CFA Level I 考试信息与规则

← 返回 [[CFA Program]]

## 🧾 题型与时长

| 项目 | 内容 |
|---|---|
| 题型 | 全部单选题（MCQ），**三选一** A/B/C |
| 总题量 | **180 题** |
| 分场 | 两场，每场 **90 题 / 135 分钟**（2 小时 15 分） |
| 节奏 | 平均 **90 秒/题** |
| 中场休息 | 两场之间有一次可选休息（约 30 分钟） |
| 倒扣分 | **无**。答错不扣分 → 绝不留空 |
| 形式 | 机考，Prometric 考点，一年四个考试窗口（2/5/8/11 月） |

> 三选一意味着**纯蒙的期望正确率是 33%**。这也意味着：能排除掉一个明显错的选项，正确率就跳到 50%。L1 的很多题拿分靠的是排除法，不是完整算出答案。

## 🎯 及格线（MPS）

- **MPS = Minimum Passing Score**，由 CFA Institute 董事会用 Angoff 法设定，**从不公布具体数值**。
- 业内普遍估计在 **65–70%** 区间浮动，逐次考试不同。
- **不是按比例淘汰**（不是排名制），理论上所有人都能过。
- 成绩单会给：Pass/Fail + 每个科目你的表现区间 vs. 该次考试**第 90 百分位考生**的表现。

**实操结论**：给自己定的目标是**模考稳定 75%+**，留出考场发挥波动的余量。70% 是危险区。

## 📚 Practical Skills Module（PSM）

- Level I 考生需在 Learning Ecosystem 中完成 **一个 PSM**（如 Financial Modeling、Python Programming Fundamentals 等）。
- **不计入考试分数**，但属于项目要求。
- ⚠️ 具体是哪些可选模块、截止时间要求，**以你 LES 账号里的实际提示为准** —— 这块 CFA 协会调整过几次，别信任何二手说法（包括我的）。
- 💡 你有 Python + 量化背景，**Python Programming Fundamentals 对你几乎是零成本**，建议现在就顺手刷掉，别留到考前占用复习时间。

## 🚫 考场规则速记

- 只能带：护照/证件、计算器（可带备用电池）、Prometric 提供的可擦写板和笔。
- **不能带**：手表（任何款式）、手机、水、纸质笔记、自己的草稿纸。
- 到场后所有个人物品存柜，中途出场需重新安检。
- 迟到超过规定时间直接取消资格，建议提前 60 分钟到。
